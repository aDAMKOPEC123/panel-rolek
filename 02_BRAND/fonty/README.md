# fonty/
Pliki fontów marki (.woff2, ewentualnie .ttf). Domyślnie używamy fontów wbudowanych w HyperFrames (Playfair Display, Montserrat), więc ten folder może być pusty.
- Nazewnictwo: `NazwaFontu-Waga.woff2`, np. `Lora-SemiBold.woff2`.
- Po dodaniu wpisz nazwę pliku w `config.json` -> `fonty.plik_naglowki` / `fonty.plik_tekst`.
- Sprawdź, czy font ma polskie znaki (ą ę ś ć ź ż ó ł ń). Bez nich nie wrzucaj.
- NIE wrzucaj fontów bez licencji na użycie komercyjne.
