# 02_BRAND
Wszystko, co sprawia, że rolka wygląda i brzmi jak Ty.

| Plik / folder | Co to |
|---|---|
| `brand.md` | ton, zakazane słowa, domyślne CTA |
| `kolory.json` | do czego służy każdy kolor (wartości hex są w `config.json`) |
| `caption-skin.json` | wybrany styl napisów i opis trzech dostępnych |
| `fonty/` | własne fonty (opcjonalnie) |
| `logo/` | logo do plansz i okładek |
| `watermark/` | mały znak wodny w rogu |

NIE wrzucaj tu nagrań ani materiałów do konkretnej rolki. To idzie do `01_PROJEKTY/<rolka>/`.
