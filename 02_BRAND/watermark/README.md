# watermark/
Mały znak wodny w rogu rolki.
- Plik: `watermark.png`, przezroczysty, ok. 300x300 px, jednolity kolor (biały albo kolor marki).
- Jeśli folder jest pusty, szablon pokazuje w rogu handle z config.json.
- Znak wodny siedzi w lewym górnym rogu w safe zone (prawy bok zajmują przyciski Instagrama).
- NIE wrzucaj dużego, kolorowego logo. Ma być dyskretny.
