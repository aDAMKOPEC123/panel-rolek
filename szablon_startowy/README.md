# Szablon startowy

Neutralne ustawienia dla nowej instalacji. Przy pierwszym uruchomieniu (`lib.mjs -> zapewnijPlikiStartowe`) panel kopiuje brakujące pliki: `config.json` do katalogu głównego i pliki z `02_BRAND/` do `02_BRAND/`. Twoje pliki nigdy nie są nadpisywane. Prawdziwe `config.json` i pliki marki są w `.gitignore`.
