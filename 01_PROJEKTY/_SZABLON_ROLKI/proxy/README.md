# proxy/
Klipy po normalizacji: 1080x1920, 30 fps CFR, H.264, -14 LUFS, opcjonalnie bez ciszy.
- Tworzy je `npm run normalizuj -- <projekt> [--cisza]`. Nazwa = nazwa z raw/ z rozszerzeniem .mp4.
- W rolka.json używaj klipów STĄD, nie z raw/.
- NIE wrzucaj ręcznie plików i nie edytuj ich. Można je skasować i wygenerować ponownie.
