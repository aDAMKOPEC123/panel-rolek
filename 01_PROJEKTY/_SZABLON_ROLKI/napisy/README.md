# napisy/
Transkrypcja i napisy.
- `transcript.json`: słowa z czasami (z `npm run transkrybuj`). Korekta: popraw pole text, czasów nie ruszaj.
- `transcript.srt`: napisy do wgrania osobno (np. TikTok, YouTube).
- `tekst.txt`: tekst do przeczytania i akceptacji. `zrodlo.txt`: z którego klipu jest transkrypcja.
- NIE poprawiaj stylu mowy (mówiony polski zostaje), tylko błędy rozpoznania: nazwy zabiegów, preparatów, liczby.
