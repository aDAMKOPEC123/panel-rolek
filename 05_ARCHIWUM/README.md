# 05_ARCHIWUM
Opublikowane rolki. Każdy folder ma tę samą nazwę co w 01_PROJEKTY, a w środku `wyniki.md`.
- Trafiają tu przez `npm run archiwizuj -- <projekt>` (pyta o link i wyniki).
- Wyniki po 7 i 30 dniach: `npm run archiwizuj -- --wyniki <projekt> --zasieg 1200 --zapisy 40 ...`
- `wyniki.csv`: wszystkie pomiary w jednej tabeli (otwiera się w Excelu), do porównywania hooków i formatów.
- NIE wrzucaj tu nieopublikowanych rolek.
