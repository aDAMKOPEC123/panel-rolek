# Checklista przed publikacją

Najpierw: `npm run sprawdz -- <projekt>` (sprawdza automatycznie większość punktów). Potem ręcznie:

## Plik
- [ ] `final/<projekt>.mp4` obejrzany w całości NA TELEFONIE, z dźwiękiem i bez
- [ ] hook czytelny w 1. sekundzie, bez dźwięku też wiadomo, o co chodzi
- [ ] napisy bez literówek, nazwy zabiegów i preparatów poprawne, polskie znaki OK
- [ ] żaden tekst nie wchodzi pod przyciski i opis IG
- [ ] CTA na końcu

## Zasady
- [ ] zero obietnic i gwarancji ("na zawsze", "gwarantuję", "wyleczy")
- [ ] przed/po ma dopisek o indywidualnym efekcie
- [ ] twarz klientki tylko ze zgodą (`zgoda na wizerunek: tak` w brief.md)
- [ ] podologia: bez szokującego startu, ostrzeżenie w opisie jeśli trzeba, bez diagnoz
- [ ] muzyka z licencją albo dodana w aplikacji

## Publikacja
- [ ] w aplikacji IG włączone „Prześlij w najwyższej jakości” (Ustawienia > Wykorzystanie danych i jakość multimediów), wgrywaj przez Wi-Fi, plik final bez dodatkowej kompresji w innych aplikacjach
- [ ] warianty hooka (jeśli są w `final/warianty/`): wrzuć jako rolki testowe i porównaj „% pominięć” po 24-48 h
- [ ] okładka `final/okladka.jpg` wgrana, tytuł widoczny w kadrze 3:4 siatki
- [ ] opis z `brief.md` (mówiony, krótki), 5-10 hashtagów (lokalne + branżowe)
- [ ] oznaczona lokalizacja gabinetu
- [ ] muzyka dodana w aplikacji, jeśli "dodam w IG" (cicho pod głosem)
- [ ] TikTok: napisy z `napisy/transcript.srt` albo wbudowane (już są w filmie)
- [ ] po 2-3 dniach: w panelu (krok Publikacja, „📈 Wyniki z Instagrama”) wpisz % pominięć w 3 s, średni czas oglądania, wysłania i sekundy spadków z wykresu utrzymania
- [ ] po publikacji: `npm run archiwizuj -- <projekt>` i wyniki po 7 dniach
