# muzyka/
Tylko muzyka, do której masz licencję na użycie w social media (np. kupiona w bibliotece stockowej, własna, CC0).
- Obok każdego pliku: `<plik>.LICENCJA.txt` z: źródło, autor, typ licencji, link, data zakupu/pobrania.
- Bez pliku licencji = nie używamy w renderze.
- Trendujące audio z Instagrama dodajesz w aplikacji IG, NIE pobierasz go tutaj.
