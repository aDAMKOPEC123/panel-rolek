# 00_INBOX
Wrzucasz tu WSZYSTKO prosto z telefonu, bez sortowania i bez zmiany nazw (AirDrop, kabel, Google Drive).
- `npm run inbox` pokazuje listę z długością, rozdzielczością, fps i datą.
- `npm run nowa-rolka -- <kategoria> "temat" --z-inbox` zakłada rolkę i przenosi tu wszystko do jej raw/.
- `npm run inbox -- --do <projekt> plik1 plik2` przenosi wybrane pliki do istniejącej rolki.
- NIE trzymaj tu plików na stałe. Co nie trafiło do rolki: do 03_BIBLIOTEKA (b-roll) albo do kosza.
